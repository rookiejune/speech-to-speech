# S2ST 具体指标

日期：2026-07-31  
更新：2026-08-04
状态：内部评估标准

## 1. 评估原则

后续评估不能只依赖 Token Loss。V1 已经说明：训练 Loss 较低不代表最终语音质量好，也不代表 Codec 表征适合翻译。

每个阶段至少需要同时看四类结果：

1. 任务质量：ASR、MT、TTS、S2TT、T2ST、S2ST 的主指标；
2. 稳定性：长输入、不同说话人、噪声、重复生成、边界条件；
3. 能力保持：训练语音任务前后，LLM 原有文本/MT/指令能力是否退化；
4. 效率：首包延迟、RTF、显存、吞吐、单次前向 vs 多次前向。

最终模型选择以 Stage 3 的直接 S2ST 质量、稳定性和效率为主。ASR、MT、TTS、S2TT 和 T2ST 指标用于能力保持、分解诊断和 teacher 上限评估，不替代直接 S2ST 指标。

## 2. Stage 0：TTS + MT 指标

训练任务与初始损失权重：TTS 0.9，MT 0.1。

比较对象：

- Stage 0 外部 acoustic generator 的 reconstruction upper bound；
- 强特殊 Token、少量特殊 Token、纯文本 Prompt 三种接口。

核心指标：

| 指标 | 目的 | 备注 |
| --- | --- | --- |
| 可懂度 | 判断生成语音是否能被正确听懂 | 可用生成语音再 ASR 的 WER/CER 辅助评估 |
| 自然度 | 判断语音是否自然 | 建议固定样本人工 MOS 或 pairwise preference |
| 说话人相似度 | 判断音色条件是否被保持 | 可用 speaker similarity 模型 + 人工复核 |
| Codec Token 稳定性 | 判断 token 预测是否崩溃 | 看重复、异常长度、非法 token、提前终止 |
| 长文本稳定性 | 判断长句/长段落是否退化 | 关注漏读、重复、截断、韵律崩坏 |
| 文本能力保持 | 判断 TTS 训练是否损害 Qwen3 | 用固定 MT/文本理解回归集 |
| 效率 | 判断是否具备工程可用性 | 首包延迟、RTF、显存、吞吐 |

最低 gate：

- 生成语音基本可懂、稳定；
- 自然度和说话人相似度接近 Spark-TTS；
- 长文本没有系统性重复/截断；
- Qwen3 文本 MT 能力无明显退化。

## 3. Stage 1：ASR + TTS + MT 指标

训练任务与初始损失权重：ASR 0.45，TTS 0.45，MT 0.1。

比较对象：

- Stage 0 TTS；
- 同规模 ASR 模型；
- Qwen-ASR / Qwen-TTS；
- Stage 1 内部 ASR + MT + TTS 三级闭环。

ASR 指标：

| 指标 | 目的 |
| --- | --- |
| WER / CER | 基础识别准确率 |
| 实体准确率 | 人名、地名、组织、术语 |
| 数字准确率 | 金额、日期、时间、编号 |
| 长语音稳定性 | 长输入下是否漏识别或重复 |
| 鲁棒性 | 不同说话人、语速、噪声条件 |

TTS 指标沿用 Stage 0，但必须额外比较：Stage 1 TTS 是否相对 Stage 0 退化。

LLM 能力保持指标：

- 文本 MT 回归；
- 通用文本理解回归；
- 指令遵循回归；
- 多轮 Prompt 格式稳定性。

最低 gate：

- ASR 接近同规模语音模型；
- TTS 接近 Stage 0；
- 文本 MT 没有明显退化；
- 同一模型可通过三次前向稳定完成 ASR + MT + TTS 闭环。

## 4. Stage 2：S2TT + T2ST + ASR + TTS + MT 指标

训练任务与初始损失权重：ASR、S2TT、TTS、T2ST 各 0.225，MT 0.1。

比较对象：

- Qwen3 原始文本 MT；
- Stage 1 ASR + Qwen3 MT；
- Qwen3 MT + Stage 1 TTS；
- Stage 2 直接 S2TT / T2ST。

S2TT 指标：

| 指标 | 目的 |
| --- | --- |
| 自动翻译指标 | 评估整体翻译质量，可用 BLEU/COMET/chrF 等 |
| 语义相似度 | 判断核心语义是否保持 |
| 实体/数字准确率 | 防止关键事实错误 |
| 否定关系准确率 | 防止意义反转 |
| 与 ASR+MT 差距 | 衡量直接 S2TT 是否接近级联上限 |

T2ST 指标：

| 指标 | 目的 |
| --- | --- |
| 翻译准确性 | 生成语音再 ASR 后与目标参考比较 |
| 可懂度 | 判断语音是否清楚 |
| 自然度 | 判断输出是否像正常目标语言语音 |
| 说话人相似度 | 如果任务要求保留音色，需要单独评估 |
| 与 MT+TTS 差距 | 衡量直接 T2ST 是否接近级联上限 |

最低 gate：

- S2TT 接近 Stage 1 ASR + Qwen3 MT；
- T2ST 接近 Qwen3 MT + Stage 1 TTS；
- 实体、数字、否定关系没有明显退化；
- Stage 1 的 ASR/TTS 能力仍保留。

## 5. Stage 3：S2ST + S2TT + T2ST + ASR + TTS + MT 指标

训练任务与初始损失权重：S2ST 0.7；ASR、S2TT、TTS、T2ST 各 0.05；MT 0.1。模型选择首先看直接 S2ST；其他任务指标作为退化约束和问题定位信号。

比较对象：

- Stage 1 ASR + MT + TTS 三级级联；
- Stage 2 S2TT / T2ST；
- Stage 2 TTS；
- Codec reconstruction upper bound。

核心指标：

| 指标 | 目的 |
| --- | --- |
| 翻译准确性 | 判断目标语音表达的语义是否正确 |
| 关键事实准确率 | 实体、数字、术语、否定关系 |
| 可懂度 | 判断目标语音是否能被听懂 |
| 自然度 | 判断目标语音是否自然 |
| 说话人相似度 | 判断源说话人音色是否保持 |
| 韵律/情绪保持 | 判断语气、节奏、情绪是否迁移 |
| 生成稳定性 | 重复、截断、乱码、异常 token、长度漂移 |
| 质量—效率 Pareto | 衡量直接 S2ST 的质量与效率权衡 |

推荐评估方式：

1. 目标语音再 ASR，得到目标语言文本；
2. 对目标文本计算翻译质量、实体、数字、否定关系；
3. 对目标语音计算自然度、说话人相似度、可懂度；
4. 与 Stage 1 三级级联进行 pairwise 人工比较；
5. 同时报告延迟、RTF、显存和吞吐。

最低 gate：

- 翻译准确性接近 Stage 2 S2TT 和三级级联；
- 语音质量接近 Stage 2 T2ST / TTS；
- 相对三级级联有显著延迟或算力收益；
- 质量损失和效率收益形成可接受 Pareto。

辅助任务退化约束：

- ASR、TTS 和 MT 相对各自上一阶段不得出现不可接受退化；
- S2TT 和 T2ST 相对 Stage 2 不得出现不可接受退化；
- 若直接 S2ST 提升与辅助任务退化冲突，优先保证 S2ST 主目标，但必须报告退化幅度并定位对应分解能力。

## 6. 系统效率指标

所有阶段都需要记录：

| 指标 | 说明 |
| --- | --- |
| 首包延迟 | 从输入开始到首个可播放音频片段输出 |
| RTF | 生成耗时 / 音频时长 |
| 总延迟 | 完整输入到完整输出 |
| 峰值显存 | 单请求和 batch 请求都要记录 |
| 吞吐 | tokens/s、audio seconds/s、requests/s |
| 单次 vs 三次前向耗时 | Stage 3 必须与 Stage 1 级联比较 |
| 流式能力 | 是否支持 chunk 输入、chunk 输出和稳定边界 |

## 7. 固定评估集建议

建议至少维护以下固定集：

1. 短句集：验证基本准确性；
2. 长句集：验证长上下文稳定性；
3. 数字/实体集：验证事实保持；
4. 否定/反事实集：验证语义方向；
5. 多说话人集：验证音色和鲁棒性；
6. 噪声集：验证真实输入稳定性；
7. 文本 MT 回归集：验证 LLM 原有翻译能力保持；
8. 固定听测集：用于跨 checkpoint 人工比较。

## 8. 报告格式

每次实验报告至少包含：

- 实验阶段和模型配置；
- Codec 类型和 tokenizer / prompt 格式；
- 训练数据、步数、采样比例；
- 与对应 baseline 的指标差距；
- 固定样本生成音频；
- 失败案例分类；
- 是否通过当前 gate；
- 下一步动作。

如果自动指标与人工听感冲突，以人工听感和失败案例分析作为最终决策依据。
